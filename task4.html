Формализация доказательств в Coq (Rocq)

О проекте

Coq — это интерактивная система верификации доказательств. В 2024 году проект был официально переименован в Rocq, однако оба названия продолжают использоваться. Здесь представлена формализация доказательства нижней границы размера запирающего отношения из задачи 1.

Код формализации

1. Аксиомы и определения

LEM — закон исключённого третьего для классических доказательств.
A — множество с отношением порядка Ord (рефлексивным, транзитивным и антисимметричным).
Block — аксиома, утверждающая, что B является запирающим отношением для порядка Ord.
S — инъекция множества A в булеан запирающего множества B.

Axiom LEM : forall P : Prop, P \/ not P.
Axiom A : Set.
Axiom Ord : A -> A -> Prop.
Axiom Ord_ref : forall a : A, Ord a a.
Axiom Ord_trans : forall a : A, forall b : A, forall c : A, Ord a b -> Ord b c -> Ord a c.
Axiom Ord_antisym : forall a : A, forall b : A, Ord a b -> Ord b a -> a=b.
Axiom B : A -> A -> Prop.
Axiom Block : (forall a : A, forall b : A, (B a b) -> not (Ord a b)) /\ (forall a : A, forall b : A, (not (Ord a b)) -> exists x : A, exists y : A, (Ord x a) /\ (Ord b y) /\ (B x y)).

Definition S : A -> (A -> A -> Prop) := fun a : A => fun x : A => fun y : A => (B x y) /\ (Ord x a).

2. Вспомогательная лемма nleq

Лемма о том, что в порядке для любых двух различных элементов один из них всегда не больше другого.

Lemma nleq : forall a : A, forall b : A, (a<>b) -> ((not (Ord a b)) \/ (not (Ord b a))).
Proof.
intro.
intro.
intro.
case (LEM (Ord a b)).
intro.
right.
intro.
exact(H (Ord_antisym a b H0 H1)).
intro.
left.
exact(H0).
Qed.

3. Основная теорема S_inj

Ключевая теорема об инъективности отображения S. Доказательство повторяет идею, изложенную на странице «Диаграммы импликаций».

Theorem S_inj : forall a : A, forall b : A, a<>b -> (exists x : A, exists y : A, (S a x y) /\ not (S b x y)) \/ (exists x : A, exists y : A, (S b x y) /\ not (S a x y)).
Proof.
intro.
intro.
intro.
case (nleq a b H).
intro.
destruct ((proj2 Block) a b H0) as [x Hx].
destruct Hx as [y Hy].
left.
exists x.
exists y.
split.
unfold S.
split.
exact (proj2(proj2 Hy)).
exact(proj1 Hy).
intro.
unfold S in H1.
exact(((proj1 Block) x y) (proj2 (proj2 Hy)) (Ord_trans x b y (proj2 H1) (proj1(proj2 Hy)))).
intro.
destruct ((proj2 Block) b a H0) as [x Hx].
destruct Hx as [y Hy].
right.
exists x.
exists y.
split.
unfold S.
split.
exact (proj2(proj2 Hy)).
exact(proj1 Hy).
intro.
unfold S in H1.
exact ((((proj1 Block) x y) (proj2 (proj2 Hy))) (Ord_trans x a y (proj2 H1) (proj1(proj2 Hy)))).
Qed.

4. Теорема sub_B

Утверждение о том, что S(a) всегда является подмножеством B (тавтологичное свойство).

Theorem sub_B : forall a : A, forall x : A, forall y : A, (S a x y) -> B x y.
Proof.
firstorder.
Qed.
